# REF-001 · 某狼人复仇剧（匿名示例）

> 题材：狼人 / 复仇 / 女频　框架：被放逐觉醒

## 一句话公式

**狼人复仇 = 狼族设定 + 被放逐觉醒 + 归来复仇 + AI 视觉奇观**

## 结构骨架

- **Logline**：没有显现力量被逐出王国的公主，二十年后以传奇狼后身份归来复仇
- **起承转合**：受辱逐出 → 隐忍觉醒 → 身份揭露 → 碾压复仇 → 反派追悔
- **核心反转**：第 28 集
- **主线冲突**：被否定的血统 vs 归来的绝对力量

## 前三集

| 节点 | 内容 |
|---|---|
| 开场 10 秒 | 当众审判与放逐，没有铺垫 |
| 第 1 集钩子 | 身份曝光 |
| 第 2 集升级 | 反派继续施压，女主被迫离开 |
| 第 3 集反转 | 身份（力量觉醒） |
| 首次付费卡点 | 第 8 集，狼后身份即将揭晓前 |

## 人设

**女主 · 被放逐公主**
- 视觉符号：狼族纹章、特定发色
- 性格关键词：隐忍、清醒
- 动机：夺回属于自己的一切
- **反差**：前期无力自保 vs 后期绝对力量
- **亮出方式**：第 3 集用一次失控的力量爆发演出来，不是靠旁白解释

## 钩子与节奏

- 每 3 集一个打脸名场面
- 每 5 集一次身份或关系反转
- 情绪曲线压迫与释放交替，无连续三集单一情绪

## 可复用与不可复用

**可复制**
- 被放逐 → 觉醒 → 归来的三幕结构
- 前期弱后期强的人设反差
- 用 AI 做真人拍不起的变身与魔幻场景

**不可复制**
- 具体特效风格
- 上线时机与投流渠道
