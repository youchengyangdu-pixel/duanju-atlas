案例库

00怎么用这套模板▶

每部对标剧建一张卡，按 A–L 十二组填。填完点「导出 Markdown」，直接贴进 Obsidian 就是一个案例。

两条铁律：
① 案例库 ≠ 代表作。案例库 → 提升判断力 → 做出爆款 → 简历上的代表作。只做案例不做作品，JD 那关过不了。
② 归因必须分层。掉人不一定怪内容，可能是制作穿帮、付费墙太硬、或投流人群不对。归因错了，改的方向全错。

两个硬指标：每 3 集一个打脸名场面；每 5 集一次身份或关系反转。连续 3 集只有虐或只有爽，大概率扑。

案例库归档按「可复用维度」，不按时间。半年后你要找「扮猪吃虎在女频怎么用」，能直接翻到。

E节奏与情绪曲线平的就是问题▶
F钩子系统找同质化疲劳区▶
每集结尾钩子类型，可从：利益骤变 / 身份曝光 / 道德突破 / 情感背叛 / 悬念 / 羞辱 / 危机 / 欲望 里选。连续 3 个同类型会疲劳。
G台词功能▶
每句标功能：推剧情 / 立人设 / 埋钩子 / 给情绪。只「抛信息」的台词标为可删。
H镜头与视听▶
I上线数据分集流失曲线最关键▶
分集流失记录：填「集数 + 留存%」，找出陡降点。
J归因分析四层，别都怪内容▶
内容层：连续同类型钩子、流失平缓下滑　|　制作层：流失集中在某场戏、评论骂画面　|　 商业层：流失点正好在付费墙　|　渠道层：第 1 集就大量流失、评论说「被骗了」
K可复用结论一句话公式▶
L案例归档按可复用维度打标签▶
按题材 / 结构 / 人设 / 数据表现 / 失败归因打标签。不要按时间归档，否则半年后找不到。
M状态资产与视觉依赖本案新增 · 防止核心设定被抹平▶
